**Most Commonly used Line Commands**

This Command `mkdir` is used to make an empty folder , you can also put any name for it.

Ex: `mkdir computer science/`

---

This Command Line,`touch` is used to create a new empty file (.md or .txt).

Ex: `touch textbook.txt`

---
**How To Go Back A Directory:**

You can go back by typing `cd ..`

**How to change / go into a directory:**

`cd <folder name>`

---
## Other commands
1. `Is` This list directory files
2. `pwd` This shows the current directory
3. `clear` This clears the terminal screen

   ---
   ## Tips:
   - Anything in < > is a place holder, you can put a folder name of your choice
   - make sure to not include the brackets when doing so
   - use`pwd` to confirm where you're at before running the command
   - *Reminder:* Directory = Folder
